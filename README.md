# EFECTO

Tablero de sonidos para teatro, cultos y eventos en vivo. Aprietas un botón y
suena: sin buscar archivos, sin abrir reproductores, sin internet.

**[→ Descargar](https://mfnc1996.github.io/EFECTO-descargas/)**

| **Windows** | [EFECTO-1.0.0-windows.zip](https://github.com/MFNC1996/EFECTO-descargas/releases/download/v1.0.0/EFECTO-1.0.0-windows.zip) · Windows 10 y 11 |

La primera vez el sistema desconfía, porque la aplicación no está firmada con
los certificados de pago de Apple ni de Microsoft. Se abre igual:

- **Mac** — clic derecho sobre EFECTO → **Abrir**, y **Abrir** otra vez. Si tu
  Mac es muy reciente: **Ajustes del Sistema → Privacidad y seguridad → Abrir
  de todos modos**.
- **Windows** — en la pantalla azul, **Más información → Ejecutar de todas
  formas**.

Aquí solo viven las descargas y la página. El código es privado.
